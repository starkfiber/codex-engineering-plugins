# Public qualification and gaps

Reverse Lab3.3.2 and Apple Blueprint2.0.0-alpha.3 are first public source packages from previously local plugins. Versioned source, manifests and community CI are new public proof; prior private case outcomes remain historical.

Reverse Lab community checks cover case creation/verification, malformed and stale records, supported coverage schemas, dependency invalidation, job reservation/failure/owned-child cleanup and hash-reviewed replay. Coverage fixtures are explicitly synthetic; no private Etcher artifact or full original-application analysis is shipped. Runtime gates cannot pass from static records. POSIX cleanup is the qualified execution family; Windows is not.

The optional REA bridge qualifies an independently installed rea-agents6.8.0 package and its declared Node range. A maintainer-only actual tools/list probe is a server discovery/cleanup check, not proof of every provider or a full artifact investigation. Default checks do not download/execute the upstream engine.

Apple community checks cover routing, project/hash helpers, archive preflight, evidence and stable-release gates, malformed inputs, relocation and actual stdio tool discovery. The sample is synthetic; source-bound old platform/hardware evidence is not carried forward as current acceptance. Read-only helper success is not compiler/UI/accessibility/signing/App Review/restore qualification. Apple remains alpha.

Next: independently reproduce core workflows, improve current-schema coverage adapters, investigate supported Windows process cleanup, add a reviewed macOS sample test matrix, and contribute source-linked findings without private data. Keep per-plugin release notes and exact tested revisions.
