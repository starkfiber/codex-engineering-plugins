# Engineering council

Use only when requested or otherwise authorized. Assign independent questions with explicit artifacts, output location and scope. Parallelize independent reads; give one owner each implementation file. Use the available agent slots rather than promising a fixed council size. If delegation is unavailable, perform a sequential review and disclose it.

Useful roles (choose what the task needs):
- Investigator: mechanism, competing explanations, smallest discriminating inspection.
- Reconstruction engineer: behavior contract, integration choices and fidelity gaps.
- Verification engineer: falsification cases, evidence coverage and reproducible checks.
- Reliability reviewer: lifecycle, errors, provider limits and resumption.

Give each reviewer the user question and raw evidence. For an independent check, withhold the lead's preferred conclusion until the reviewer has returned. Require findings to distinguish observations from hypotheses and state the next check needed. Do not invent consensus, agent identities or test results.

The lead reconciles disagreements using evidence. Record unresolved dissent with the affected claim; majority vote is not proof. Apply relevant findings, rerun affected checks and give the user one coherent result. Council participation does not expand the task or authorize external communication.

Record roles actually used, reviewed artifacts, material findings, decisions and remaining uncertainty in the case's council.md when useful. Do not save private reasoning transcripts.
