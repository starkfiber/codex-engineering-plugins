# Public setup and REA boundary

The community plugin contains original workflow skills and file/process helpers. It does not bundle or auto-register the third-party REA engine. Use the repository marketplace for the skill; read docs/REA.md for an optional explicit integration with an independently installed rea-agents6.8.0 package.

The previous machine-specific3.3.1 installer copied an existing engine, changed owned Codex registration and disabled a legacy duplicate. It is not the public install path. Do not reproduce its private absolute paths, migrate unrelated configuration or mutate installed caches.

Upstream: https://github.com/morluto/rea (MIT). Discover current provider schemas. A missing decompiler is a provider limitation; no source guide removes model quotas or grants execution permission. Keep actual engine inspection, helper arithmetic and runtime proof distinct.
