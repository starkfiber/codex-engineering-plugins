**Degree:** Master's
**Language:** English

# Chapter 1: Introduction

## Proposal and rationale

This synthetic proposal demonstrates the notebook workflow. No participants were recruited and no empirical findings exist. A library catalogue is used as a provisional evaluation context. WCAG 2.2 provides a keyboard-operation criterion with a path-dependent input exception (W3C, 2024, SC 2.1.1). The proposed study would examine representative search and record-selection tasks. It does not claim that any actual library has failed the criterion, or that all accessibility needs are covered by keyboard testing.

# Chapter 3: Methodology

## Planned method

Define catalogue tasks before evaluation, record keyboard actions and task outcomes, and retain reproducible barrier descriptions. Participant research requires an approved ethics and consent process before recruitment. Sampling, analysis and accessibility review remain to be designed with the researcher. No data or results are supplied by this example.
